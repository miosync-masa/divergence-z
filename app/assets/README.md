# App icon

Put the app icon here as `icon.png` (1024×1024 PNG, transparent background allowed).
electron-builder generates the macOS `.icns` and Windows `.ico` from it at build time.
Until it exists, the default Electron icon is used.

macOS style: keep the artwork inside the centered ~824×824 rounded square and leave the rest
transparent, so the icon matches other apps in the Dock (macOS does not round it for you).
